# Ted Default Icons

A professional set of file and folder icons for the Ted editor.

## Features

- **Semantic Identification**: Instantly recognize file types by their colored icons.
- **Modern Design**: High-contrast, pixel-perfect SVGs.
- **Performance**: Extremely lightweight, registered directly through the Ted Icons API.

## Supported File Types

- TypeScript (`.ts`)
- React/JSX (`.tsx`, `.jsx`)
- JavaScript (`.js`)
- JSON (`.json`)
- CSS (`.css`)
- HTML (`.html`)
- Rust (`.rs`)
- Standard Folders

## Installation

Install via the Ted Marketplace and activate it in the extensions panel.
